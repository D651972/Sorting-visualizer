# Sorting-visualizer
This project helps one to visualize a sorting algorithm. Each element of the array is displayed as a bar. The operations are colour coded such that:  
1. Red - Swap 
2. Blue - Comparison 
3. Green - Element is in sorted position It compares the time taken by the different algorithm for sorting the array.

Javascript (p5.js)
